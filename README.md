# Tetris на Rust

Сервер на Rust (axum + tokio), отдаёт страницу и гоняет состояние игры по WebSocket.
Вся логика тетриса — генерация фигур, столкновения, повороты с wall-kick, сгорание
линий, очки, уровни, hold, призрак фигуры, game over — живёт на сервере.
Браузер только рисует canvas и отправляет нажатия клавиш.

## Сборка и запуск

```sh
cargo build --release
TETRIS_ADDR=127.0.0.1:8090 ./target/release/tetris
```

## Управление

| Клавиши | Действие |
| --- | --- |
| ← → | сдвиг |
| ↑ / X | поворот |
| ↓ | мягкое падение |
| Space | жёсткое падение |
| C / Shift | hold |
| R | новая игра |

## Файлы

- `src/game.rs` — правила игры и состояние (`Game`, `Piece`, `Action`)
- `src/main.rs` — HTTP-сервер и цикл WebSocket
- `static/index.html` — рендер и ввод
